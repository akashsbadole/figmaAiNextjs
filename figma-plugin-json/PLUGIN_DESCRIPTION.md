# JSON to Figma - System Design Generator

**Transform JSON data into professional Figma designs instantly.** Perfect for designers, developers, and product teams who want to speed up their design workflow.

## ✨ What You Can Create

Generate complete design systems, UI templates, forms, dashboards, and components from simple JSON structures. No coding required—just paste your data and click convert!

### 🎨 Perfect For:
• **Design Systems** - Generate entire component libraries from JSON schemas
• **UI Templates** - Create reusable templates for cards, forms, and modals
• **Mockups & Prototypes** - Convert wireframe data to high-fidelity designs
• **Dashboards** - Build analytics panels and data visualizations
• **Forms & Layouts** - Generate login screens, signup flows, and input fields
• **Mobile Screens** - Create app interfaces from structured data
• **Style Guides** - Build consistent design documentation

## 🚀 Key Features

✓ **JSON to Figma Conversion** - Instantly convert JSON into editable Figma elements
✓ **Multiple Element Types** - Text, rectangles, containers, and images
✓ **Auto-Layout Support** - Automatic spacing and responsive designs
✓ **Style Customization** - Colors, padding, borders, corner radius, and more
✓ **Nested Structures** - Unlimited nesting for complex layouts
✓ **Array Handling** - Create multiple elements from JSON arrays
✓ **Built-in Templates** - Ready-to-use examples for quick starts
✓ **Real-time Preview** - See your designs materialize instantly
✓ **Error Validation** - Helpful messages for JSON formatting issues

## 💡 How It Works

1. **Paste Your JSON** - Copy your JSON data into the plugin
2. **Define Structure** - Use simple properties (type, text, color, etc.)
3. **Customize Styling** - Set colors, sizes, spacing, and layouts
4. **Click Convert** - Watch your design appear in Figma
5. **Edit & Iterate** - All elements are fully editable in Figma

## 📖 Example JSON

Create a beautiful card in seconds:

```json
{
  "type": "container",
  "backgroundColor": "#FFFFFF",
  "padding": 24,
  "cornerRadius": 12,
  "children": [
    {
      "type": "text",
      "text": "Welcome Back!",
      "fontSize": 28,
      "fontWeight": "Bold",
      "color": "#000000"
    },
    {
      "type": "text",
      "text": "You have 5 new notifications",
      "fontSize": 14,
      "color": "#666666"
    },
    {
      "type": "rectangle",
      "width": 200,
      "height": 44,
      "fill": "#18A0FB",
      "cornerRadius": 8
    }
  ]
}
```
